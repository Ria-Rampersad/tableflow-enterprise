# 05 · API Specification

The authoritative, machine-readable contract is the **OpenAPI 3 spec** generated by FastAPI:
- live: `http://localhost:8000/docs` (Swagger UI, "Authorize" with a demo user) and `/redoc`
- file: `documentation/api/openapi.json` (exported from the code at build time)
- executable: `postman/TableFlow_Enterprise.postman_collection.json` (87 requests, 91 assertions)

## Conventions
| Topic | Convention |
|---|---|
| Base path | `/api/v1` (health/metrics at root) |
| Format | JSON; money as decimal **strings** (`"164.70"`) to avoid float rounding; timestamps ISO-8601 UTC |
| Auth | `Authorization: Bearer <JWT>` (users: OAuth2 password grant at `/auth/login`; machines: client-credentials at `/auth/token`). Partners: `X-API-Key`. Webhooks: HMAC signature headers |
| Idempotency | `Idempotency-Key` header required on `POST /payments`; provider orders idempotent on `(channel, external_ref)`; webhooks on `(source, event_id)` |
| Pagination | `limit` (1–500, default 50) and `offset`; responses `{ "total": n, "items": [...] }` |
| Tracing | Send/receive `X-Request-ID`; echoed in every response and error body |
| Rate limits | Partners 120/min per key, login 20/min per IP → `429` with `Retry-After` |
| Errors | `{"error": {"code", "message", "details", "correlation_id"}}` |

## Status codes
| Code | Meaning in TableFlow |
|---|---|
| 200 / 201 / 202 | OK / created / accepted for async processing (partner orders) |
| 400 | Malformed webhook or OAuth request |
| 401 | Missing/invalid/expired token, bad API key, bad webhook signature |
| 403 | Authenticated but role not allowed (RBAC) |
| 404 | Unknown resource |
| 409 | Conflict: invalid state transition, idempotency conflict, already resolved |
| 422 | Validation (`VALIDATION_ERROR`) or business rule (`UNKNOWN_SKU`, `TOTAL_MISMATCH`, `AMOUNT_MISMATCH`…) |
| 429 | Rate limit |
| 502 | Vendor rejected/unavailable for an operation that must be confirmed (refund, redemption, journal) |

## Example error
```json
{"error": {"code": "AMOUNT_MISMATCH", "message": "Amount 1.00 does not match outstanding balance 164.70",
           "details": null, "correlation_id": "9f2c1a7d0b3e4f51"}}
```
